# Domain Software and Hardware Choice Validation

Each of the eight innovation-domain cards now acts as an accessible button. Activating the card reveals exactly two choices: **Software Build** and **Hardware Build**, each with a short definition and a Lucide stock icon.

The live browser interaction test opened the AgriTech & GreenTech card, found both choices, selected Hardware Build, and confirmed `aria-expanded`, `aria-pressed`, selected-state feedback, and definition visibility. Desktop review shows the choice panel in normal card flow. The 393px mobile style uses a one-column choice panel with touch-safe controls and contained text.
